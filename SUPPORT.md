# Podrška

Za prijavu greške otvori GitHub Issue i navedi:

- model Mac računara i verziju macOS-a
- verziju igre prikazanu u donjem uglu glavnog menija
- izabranog junaka, poglavlje i težinu
- korake koji pouzdano ponavljaju problem
- snimak ekrana ili video, kada je moguće

Ne objavljuj privatne podatke ni sadržaj svog `profile.json` fajla bez prethodnog
pregleda. Igra nema mrežni nalog niti server na kome bi se napredak mogao obnoviti.
