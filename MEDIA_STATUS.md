# Current Media: VETROMIR 7.25

Updated September 12, 2026.

The current website, README and 7.25 press kit use screenshots captured in the
7.25 game. The site no longer embeds or links to a gameplay video.

The former English website trailer and six older release video files show the
previous vector artwork. They have been removed from the current repository
branches and GitHub release downloads. Three older press/promo ZIPs containing
outdated videos have also been withdrawn. Historical game installers remain
available; they are not the current release.

The [current press kit](https://github.com/srdjankotarlic/vetromir-sivi-source/releases/download/v7.25/Vetromir-7.25-Press-Kit.zip)
contains current Full HD screenshots and English/Serbian copy. It does **not**
contain a new trailer. Do not use older footage to represent the current game.

Original video files have been retained locally. Git history was not rewritten,
so historical commits/tags may still contain older media; those are not current
promotional downloads. Third-party reposts are outside this repository's control.
