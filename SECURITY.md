# Bezbednosna politika

Za ranjivost koja može da ugrozi profil igrača, integritet distributivnog paketa ili
lokalni Mac koristi GitHub opciju **Report a vulnerability** ako je omogućena. Nemoj
objavljivati funkcionalan exploit u javnom issue-u pre nego što vlasnik dobije priliku
da pripremi ispravku.

Uz prijavu navedi verziju macOS-a, verziju igre, tačne korake reprodukcije i očekivani
uticaj. Problemi balansa i obični gejmplej bagovi pripadaju standardnim GitHub issues.
